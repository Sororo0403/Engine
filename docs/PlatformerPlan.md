# 小さな3Dゲームを作れる状態までの作業

ユーザーが指定した完成条件：床と壁がある小さなステージで、主人公が移動・ジャンプでき、カメラが追従し、落下すると復帰するゲームを作れること。

以後の自律作業はこの条件に必要な機能だけを対象にする。下記を実装・検証した時点で作業を終了し、無関係なEditor機能の追加は続けない。プッシュは行わない。

- [x] 衝突用ボックスのデータ・ワールド座標変換・シーン保存の基盤（旧形式との互換性を含む）
- [ ] 衝突用ボックスをInspectorで設定し、床・壁の形状として使える
- [x] 床・壁・天井との衝突、重力、移動、ジャンプのEngine処理
- [ ] 主人公を追従するカメラ、落下時の開始位置への復帰
- [ ] Inspectorで必要な設定を編集でき、Undo／Redoと保存・読み込みに対応
- [ ] 編集シーンを保持したPlay／Stopと、ゲーム操作用の入力制御
- [ ] 床・壁・主人公を備える小さなサンプルステージ
- [ ] Debug・Releaseビルド、衝突・ジャンプ・追従・復帰・再生終了時の編集内容保持を検証

操作はWASDで移動、Spaceでジャンプを基本とする。既存の3Dモデル表示とSceneビューを使い、ゲーム用機能をEngine、制作・再生UIをEditorに置く。

実装時の基準：既存の `Editor/resources/models/box.glb` のローカル範囲は各軸 `[-1, 1]`。サンプルの衝突形状はモデルに合わせて半分の大きさを `(1, 1, 1)` とする。
