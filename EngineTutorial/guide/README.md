## 実装の確認方法

- 章では、入口の呼び出し元、処理が読むデータ、結果の反映先、失敗時や終了時の扱いをつなげて説明します。
- ソースの章番号は主な解説先です。たとえば `RuntimeScene.cpp` は章11を主とし、章01ではその初期化・更新・描画・終了を追います。
- 外部配布物は、一覧に個別パスを記録し、自作コードとの接続点・プロジェクト設定・ライセンスを該当章で確認します。Gameのデータは、形式・参照・スクリプトの実例として記録します。
- 着手時点のVisual Studio向けEngineTutorialは「旧教材」として記録します。教材プロジェクトの形式を切り替えたあとの履歴も元のコミットから参照できます。

棚卸しの再確認には、`git ls-tree -r --name-only 5114bcd4ee2b` のパス一覧と、TSVの先頭列を照合します。章の予定を埋めた段階と、実装を読んで説明と確認手順を書き終えた段階は区別します。
