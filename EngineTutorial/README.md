# EngineTutorial

実際のC++を読んで問いに答え、コードを書いて動きを確かめる教材です。このフォルダは既存Editorで開けるプロジェクトです。

1. Editorの **File → Open Project…** からこのフォルダの `project.json` を開きます。
2. **File → Export Game…** で新しいフォルダへ出力します。書き出しには、対応するRelease x64のRuntimeが必要です。
3. 出力した `Game.exe` を起動します。目次から第1章を選び、**コード実習へ → コードを書く** と進みます。

コード欄から **実行** を押すと、その場で結果が出ます。書き換えたコードは同じシーンのコード欄に保持されるので、続けて試せます。
