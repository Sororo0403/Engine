# EngineTutorial

このエンジンを、Editor・Engine・Runtimeのコードと実行結果を見比べながら学ぶ教材です。

1. Visual Studioで `Engine.slnx` を開き、**Editor** をスタートアップ プロジェクトに設定します。
2. Editorを起動し、**File → Open Project…** からこのフォルダの `project.json` を開きます。
3. 起動シーンの **00-Index** で **Play** を押し、Gameビューのボタンから第1章を開きます。編集状態から章を開く場合は、Assetsの **Scenes** で該当シーンを開きます。

C++の課題は同じソリューションのEngine・Editor・Runtimeで試します。変更後は、起動しているアプリを閉じてから再ビルドします。
